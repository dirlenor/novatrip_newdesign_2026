# NovaTrip — homepage only

Local-only Next.js homepage. All navigation stays within homepage sections. Search is a demo interaction; favorites remain local to this browser. No other content pages or backend integrations are included.

Typography: Inter headings with Caveat handwriting accents. Hero: 70vh on desktop and tablet; content height with a 70svh minimum on mobile.

Run npm install then npm run dev. Open http://localhost:3000.

Checks: npm run lint, npm run typecheck, npm run build. Production files export to out/.

See ASSETS.md for supplied image mappings and missing artwork. Do not upload or deploy without a new explicit request.
