# NovaTrip homepage

The Next.js application and its supplied image assets are in `novatrip/`.

## Run locally

```sh
cd novatrip
npm install
npm run dev
```

Open http://localhost:3000.

## Validation

```sh
npm run typecheck
npm run lint
npm run build
```

The homepage uses Inter and Caveat fonts, GSAP hover interactions, and ScrollTrigger travel-path animations. Search and login are preview controls; backend booking and authentication are not implemented.

Build output, local hosting metadata, and duplicate original asset files are excluded from Git.
